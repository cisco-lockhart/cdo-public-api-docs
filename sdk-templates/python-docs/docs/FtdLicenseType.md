# FtdLicenseType

A license that can be applied to an FTD. Tenants that are not MSLA-enabled must use the Smart Licensing licenses ('BASE', 'CARRIER', 'THREAT', 'MALWARE', 'URLFilter'). MSLA-enabled tenants must use the MSLA licenses ('MSLA-CSF-ESS', 'MSLA-CSF-ADV', 'MSLA-CSF-AMP', 'MSLA-CSF-URL'), and may only specify entitlements their tenant actually holds. A single request must not mix the two families.
